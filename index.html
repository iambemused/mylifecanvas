Backup & Restore

Your data is stored in your browser's localStorage. It persists between sessions but can be lost if you clear browser data, switch browsers, or move the file to a different location.

💾 Full Backup (Recommended):
1. Open ⚙ Settings
2. Find the Data Backup & Restore section
3. Click 📥 Export All Data
4. Save the JSON file to a safe location
This backs up everything: tasks, priorities, victories, contacts, settings, and notes.

To restore from backup:
1. Open ⚙ Settings
2. Click 📤 Import Data
3. Select your backup file
4. Confirm when prompted (this replaces all current data)

Recommendation: Export your data regularly, especially before updating the application file or clearing browser data.
